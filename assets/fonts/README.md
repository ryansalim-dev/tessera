# Fonts

- **Fraunces** (SemiBold 600, ExtraBold 800): titles. SIL Open Font License 1.1, see `OFL-fraunces.txt`.
- **Nunito** (Medium 500, Bold 700, ExtraBold 800): UI text and tile digits. SIL Open Font License 1.1, see `OFL-nunito.txt`.

Static instances from Google Fonts, bundled so the app never fetches fonts at runtime.
